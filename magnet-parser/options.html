qBittorrent Setup Guide

  1. Enable WebUI: In qBittorrent, open Tools > Options > Web UI and check "Web User Interface (Remote control)".
  2. Set Port & Credentials: Choose an IP address / port (default is 8080) and set your WebUI username and password.
  3. Automatic Header Spoofing: MagnetParser uses Chrome's declarativeNetRequest API to seamlessly match the origin and referer of your qBittorrent host, avoiding cross-site request blocks without needing to modify qBittorrent configuration files.
